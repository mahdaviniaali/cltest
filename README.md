# Crawler Project

پروژه کرالر وب با Python و رابط کاربری Frontend.

## ساختار پروژه

```
cltest/
├── docs/          # مستندات پروژه
├── project/       # کرالر Python
└── frontend/      # رابط کاربری
```

## شروع سریع

### Backend (Crawler)

```bash
cd project
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
python main.py
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## مستندات

مستندات کامل در پوشه [`docs/`](docs/) قرار دارد.
