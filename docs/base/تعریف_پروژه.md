## One-liner

> یک **محصول کرالر وب** با Python و UI، که داده structured از وب جمع می‌کند، قابل مشاهده و repeatable است — با **documentation-first** و تفکیک **Platform / Application**.

## الهام و تفاوت با site-map

| محور | site-map (پروژه قبلی) | cltest (پروژه جدید) |
|---|---|---|
| ambition | Enterprise Web Acquisition Runtime | Crawler product — pragmatic MVP → mature |
| architecture | Hexagonal + DDD + Acquisition Package | Layered crawler (Platform core + App crawlers) |
| output | Acquisition Package (high-fidelity) | JSON structured records (+ future API/UI) |
| doc maturity | Foundation pillars (Principles → Language → Contracts → Capabilities) | Layered L1–L5 + base docs |
| phase | M1–M3 milestones enterprise | Phase 0 scaffold → Phase 1 real site → Phase 2 API/UI |

> site-map **مرجع تجربه** است — نه copy-paste معماری. اصول fidelity و doc-first منتقل می‌شوند؛ complexity enterprise فقط در صورت نیاز واقعی.

## Purpose (هدف)

جمع‌آوری **ground truth structured** از وب برای:

- Developer که crawl logic می‌نویسد
- Operator که نتایج را monitor می‌کند (via future UI)

**نه** یک اسکript یک‌بار مصرف — یک **محصول قابل توسعه** با مرز مشخص.

## Primary Design Principle (draft)

> **Documentation-first + Platform reuse:** هر capability عمومی در Platform؛ هر منطق site-specific در Application.

اصول کامل → [`رویکرد_پروژه.md`](رویکرد_پروژه.md).

## Formal Output Boundary (draft)

**MVP contract:**

```text
Input:  URL list + site crawler (subclass BaseCrawler)
Output: JSON file — list of structured records (site-defined schema)
Meta:   timestamp, source URL, crawl config snapshot (TBD)
```

| سطح | قرارداد | status |
|---|---|---|
| MVP | JSON array of records | ✅ shipped baseline |
| Phase 2 | REST API + same schema | ❌ draft |
| Future | richer package (site-map style) | ❌ not committed |

> قرارداد freeze → promote به L1 `platform/current_state/storage.md` + ADR.

## In Scope

- Reliable fetch + parse + store pipeline
- Extensible site crawlers (subclass pattern)
- Layered documentation (L1–L5)
- Future: UI for viewing/managing crawl results
- Future: API for frontend/integration

## Out of Scope (فعلی)

| item | reason |
|---|---|
| Distributed crawl cluster | complexity — Phase N+ |
| Real-time streaming | not MVP |
| CAPTCHA bypass | legal/ops risk |
| AI/LLM extraction inside crawler | Host responsibility (lesson from site-map DP4) |
| Embedding / RAG / search indexing | downstream consumer |
