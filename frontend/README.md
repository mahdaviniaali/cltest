# Frontend

رابط کاربری — React + Vite.

## قابلیت‌ها

- ثبت‌نام / ورود / خروج
- CRUD فیلتر جستجو (برند، مدل، سال، قیمت، کارکرد، موقعیت)
- فعال / غیرفعال کردن فیلتر

## شروع

```bash
# ترمینال ۱ — API
cd project
pip install -r requirements.txt
python scripts/init_db.py
python run_api.py

# ترمینال ۲ — UI
cd frontend
npm install
npm run dev
```

مرورگر: `http://localhost:5173`
